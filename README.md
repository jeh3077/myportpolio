#### 1. 0과 1로 숫자를 표현하는 방법 : 이진법
* 0과 1을 나타내는 가장 작은 정보 단위를 **비트**라고 한다.
* **ex) 2비트로 표현할 수 있는 정보:** 00 / 01 / 10 / 11 (따라서 n개의 비트로 표현할 수 있는 상태는 $2^n$가지)
* **단위:** 프로그램의 크기를 말할 때는 비트보다 큰 단위인 **바이트(Byte)**를 사용한다. (1 byte = 8 bit)
* **음수 표현:** 0과 1로 음수 표현하기 위해 **2의 보수**를 사용.

#### 1-2 확인문제
1) 2000MB -> 2GB  
2) 1000GB = TB / 1000kB = 1MB / 1000MB = 1GB / 1024 bit  

#### 2. 0과 1로 문자를 표현하는 방법
* **문자 집합:** 컴퓨터가 이해할 수 있는 문자의 모음
* **인코딩:** 문자를 0과 1로 이루어진 문자코드로 변환하는 과정
* **디코딩:** 0과 1로 표현된 문자 코드를 다시 문자로 변환하는 과정
* **주요 방식:** * 아스키 코드(7비트+패리티 1비트), EUC-KR(완성형), 유니코드(통합 문자 집합)
  * 유니코드 인코딩 방식: utf-8, utf-16 등

#### 2-1. 확인문제  
1. hongong  
2. **EUC-KR 설명:** 한국어 인코딩 방식 / 완성형 / 하나의 완성된 글자에 코드 부여 / 모든 한글 표현 불가  
3. **안녕(유니코드 변환):** * 안 => C548 => 11101100 10010101 10001000  
   * 녕 => B155 => 11101011 10000101 10010101  
   * **답:** 1110 1100 1001 0101 1000 1000 1110 1011 1000 0101 1001 0101 (2)
