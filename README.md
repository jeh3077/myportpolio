## 🗓️ Day 1
### 📘 Chapter 1. 컴퓨터 구조 서론
<details>
<summary><b>핵심 부품 4가지 및 정보의 종류 (클릭)</b></summary>

#### 1. 컴퓨터가 이해하는 정보
* **데이터:** 숫자, 문자, 이미지 등 정적인 정보
* **명령어:** 데이터를 움직이고 작동시키는 정보 (ex. "1과 2를 출력하라")

#### 2. 핵심 부품 4가지
* `CPU`: 산술논리연산장치(ALU), 제어장치, 레지스터로 구성 (두뇌 역할)
* `메모리`: **실행 중인** 프로그램의 명령어와 데이터 저장
* `보조기억장치`: 전원이 꺼져도 데이터를 보관 (HDD, SSD)
* `입출력장치`: 마이크, 스피커, 키보드 등 외부와의 통신

</details>

### 🔢 Chapter 2. 데이터 표현 (이진법 & 인코딩)
<details>
<summary><b>비트(Bit)와 문자 인코딩 정리 (클릭)</b></summary>

* **비트(Bit):** 0과 1을 나타내는 최소 단위
* **바이트(Byte):** 8개의 비트를 묶은 단위 ($1 \text{ Byte} = 8 \text{ bits}$)
* **인코딩(Encoding):** 문자를 0과 1로 변환하는 과정 (ASCII, EUC-KR, UTF-8 등)
* **2의 보수:** 음수를 표현하기 위해 사용 (모든 비트를 뒤집고 1을 더함)

</details>

## 🗓️ Day 2
### ⚙️ Chapter 4 & 5. CPU 작동 원리 및 성능 향상
<details>
<summary><b>레지스터 종류 및 명령어 사이클 (클릭)</b></summary>

#### 1. 반드시 알아야 할 레지스터
| 레지스터명 | 역할 |
| :--- | :--- |
| **PC (Program Counter)** | 다음에 실행할 명령어의 주소 저장 |
| **IR (Instruction Register)** | 현재 해석할 명령어를 저장 |
| **MAR / MBR** | 메모리의 주소 및 주고받는 데이터를 저장 |
| **Flag Register** | 연산 결과나 CPU의 상태 정보를 저장 |

#### 2. 명령어 파이프라이닝
명령어 처리 과정을 단계별로 나누어 **동시에 실행**하여 성능을 높이는 기법입니다.
* **위험 요소:** 데이터 위험, 제어 위험, 구조적 위험

</details>

## 🗓️ Day 3
### 🧠 Chapter 6. 메모리와 캐시 메모리
<details>
<summary><b>RAM의 종류와 캐시 메모리 원리 (클릭)</b></summary>

* **DRAM:** 데이터가 동적으로 사라짐 (주기억장치용)
* **SRAM:** 속도가 빠르고 데이터가 유지됨 (캐시 메모리용)
* **캐시 메모리:** CPU와 메모리 사이의 속도 차이를 줄이기 위한 공간
    * `참조 지역성의 원리`: CPU가 사용할 법한 데이터를 예측하여 가져옴

</details>

### 💾 Chapter 7. 보조기억장치 (RAID)
<details>
<summary><b>HDD, SSD 및 RAID 구성 (클릭)</b></summary>

* **RAID 0:** 스트라이핑 (속도 향상, 안전성 낮음)
* **RAID 1:** 미러링 (복사본 생성, 안전성 높음)
* **RAID 5:** 패리티 분산 저장 (성능 + 안전성 균형)

</details>

## 🗓️ Day 4
### 🔌 Chapter 8 & 9. 입출력 및 운영체제
<details>
<summary><b>DMA 입출력 및 운영체제 커널 (클릭)</b></summary>

* **DMA (Direct Memory Access):** CPU를 거치지 않고 메모리와 입출력장치가 데이터를 주고받는 방식
* **커널(Kernel):** 운영체제의 핵심 서비스를 담당하는 부분
* **시스템 호출(System Call):** 사용자 모드에서 커널 모드로 전환하여 서비스를 요청하는 것

</details>

### 🧵 Chapter 10. 프로세스와 스레드
<details>
<summary><b>메모리 영역 (Stack, Heap, Data, Code) (클릭)</b></summary>



* **Code:** 기계어 명령어 저장 (ReadOnly)
* **Data:** 전역 변수, 정적 변수 저장
* **Heap:** 사용자가 직접 할당하는 동적 영역 (낮은 주소 → 높은 주소)
* **Stack:** 지역 변수, 매개 변수 저장 (높은 주소 → 낮은 주소)

</details>
